Bloc 1: Context, Objectius i Recursos

1.1. Context Històric: Què és Dart i per què existeix?

Dart és un llenguatge de programació orientat a objectes, basat en classes i desenvolupat per Google. Es va presentar l'any 2011 amb l'objectiu inicial de ser un successor del clàssic JavaScript al navegador. Tanmateix, la seva autèntica revolució va arribar el 2018 quan es va convertir en el motor essencial de Flutter.

Per què Flutter utilitza Dart?
  • Compilació doble (JIT i AOT): Durant el desenvolupament utilitza compilació Just-In-Time per permetre el Hot Reload (veure canvis a la pantalla en mil·lisegons). Per a producció, compila Ahead-Of-Time a codi màquina natiu (ARM/x86) d'alta velocitat.
  • Llenguatge orientat a la interfície d'usuari: Està optimitzat per a la creació d'interfícies fluides a 60/120 fps.
  • Estructura familiar: Té una sintaxi molt similar a Java, C# o TypeScript, fet que redueix la corba d'aprenentatge.

Bloc 2: Variables, Tipats, Col·leccions i Null Safety

2.1. Tipats Primitius i Declaració (Explícita vs Inferida)

En Dart tot és un objecte (inclosos els números i booleans). Podem declarar tipus de manera explícita o deixar que el compilador infereixi el tipus amb var.

void main() {
  // 1. Declaració Explícita
  int edat = 22;
  double preu = 19.99;
  String nom = "Laura";
  bool actiu = true;

  // 2. Inferència de Tipus (var)
  var cicle = "DAM/DAM-PMDM"; // El compilador infereix que és String
  // cicle = 123; // ERROR! No es pot canviar el tipus un cop inferit.

  // 3. Conversió de tipus (Parsing)
  int textANumero = int.parse('42');
  String numeroAText = 100.toString();

  print("Alumne/a: $nom, Edat: $edat, Curs:$cicle");
}

2.2. Flexibilitat i Mutabilitat: var, final i const

És clau entendre com es gestionen les referències de memòria en Dart:

Paraula Clau Referència (Caixa) Contingut (Valor) Moment d'assignació
var Reassignable Modificable Temps d'execució
final Immodificable (Caixa tancada) Modificable Temps d'execució (Runtime)
const Immodificable (Congelada) Immodificable Temps de compilació (Compile-time) 
void main() {
  var l1 = [1, 2];
  l1 = [3, 4];   // OK: canviem la referència
  l1.add(5);     // OK: modifiquem el contingut

  final l2 = [1, 2];
  // l2 = [3, 4]; // ERROR! No es pot canviar la referència
  l2.add(5);      // OK: es pot modificar el contingut

  const l3 = [1, 2];
  // l3 = [3, 4]; // ERROR!
  // l3.add(5);   // ERROR! Llista congelada en temps de compilació
}

2.4. Estructures de Dades / Col·leccions Bàsiques

En Flutter treballem constantment amb llistes i mapes per gestionar dades dinàmiques i estructures JSON.

void main() {
  // 1. List (Llistes ordenades)
  List<String> fruites = ['Poma', 'Plàtan'];
  fruites.add('Taronja');

  // Mètodes funcionals de col·leccions (map, where)
  var filtrades = fruites.where((f) => f.startsWith('P')).toList();

  // 2. Map (Clau-Valor, equivalent a JSON)
  Map<String, dynamic> usuari = {
    'id': 1,
    'nom': 'Enric',
    'edat': 25,
  };

  print("Nom d'usuari: ${usuari['nom']}");
}

2.5. Referències a Memòria i Còpies d'Objectes (Punters)

En Dart tot és un objecte. Quan declarem una variable, aquesta no conté directament les dades en el seu interior, sinó una referència (un punter) a l'adreça de memòria on resideix l'objecte (a la memòria Heap).

Concepte Clau: Pas per Referència
Si assignem una variable de tipus complex (com una List, un Map o una instància d'una Class) a una altra variable, no s'està duplicant la informació: totes dues variables apunten exactament a la mateixa adreça de memòria. 
void main() {
  // 1. Assignació per referència (Apuntador a la mateixa adreça de memòria)
  List<String> originals = ['Poma', 'Plàtan'];
  List<String> mateixaLlista = originals; // Copia la referència, NO les dades!

  mateixaLlista.add('Taronja');

  // Com que apunten a la mateixa adreça, totes dues variables es veuen modificades:
  print(originals);     // Sortida: ['Poma', 'Plàtan', 'Taronja']
  print(mateixaLlista); // Sortida: ['Poma', 'Plàtan', 'Taronja']

  // 2. Com fer una CÒPIA REAL (Creació d'un nou objecte en memòria)
  // Utilitzam el constructor de còpia o el Spread Operator (...)
  List<String> copiaReal = List.from(originals);
  // També vàlid: List<String> copiaReal = [...originals];

  copiaReal.add('Llimona');

  print(originals); // Es manté intacta: ['Poma', 'Plàtan', 'Taronja']
  print(copiaReal);  // Nova adreça de memòria: ['Poma', 'Plàtan', 'Taronja', 'Llimona']
}

2.6. Null Safety a Fons

Per defecte, cap variable pot contenir el valor null. Això garanteix un codi segur i evita fallades en temps d'execució.

void main() {
  String obligatori = "Hola"; // No pot ser null

  // Operador '?' per permetre nuls
  String? opcional = null;

  // Operador '?.' (Navegació segura)
  print(opcional?.length); // Imprimeix null sense llançar cap excepció

  // Operador '??' (Valor per defecte)
  String nomFinal = opcional ?? "Usuari Anònim";

  // Operador '??=' (Assignació si és null)
  opcional ??= "Valor Assignat";

  // Operador '!' (Forçar no-nul·litat - atenció: utilitzar amb precaució)
  print(opcional!.toUpperCase());
}

Bloc 3: POO, Asincronia i Enllaç amb Flutter

3.1. Estructures de Control i Expressions Idiomàtiques

void main() {
  bool teAcces = true;

  // Operador Ternari
  String estat = teAcces ? "Accés Permès" : "Accés Denegat";

  // Collection If i Spread Operator (...) en llistes
  List<String> opcionsBase = ['Inici', 'Perfil'];
  List<String> menu = [
    ...opcionsBase,
    if (teAcces) 'Panell d\'Administració',
  ];

  print(menu); // ['Inici', 'Perfil', 'Panell d\'Administració']
}

3.2. Funcions i Paràmetres Nombrats

Aquest punt és fonamental per entendre la creació de ginys (Widgets) a Flutter.

// Funció amb paràmetres nombrats ({}) i opcions requerides (required)
void crearTargeta({
  required String titol,
  String? subtitol,
  double elevacio = 2.0,
}) {
  print("Targeta: $titol ($subtitol) - Elevació: $elevacio");
}

void main() {
  // Cridem la funció indicant el nom dels paràmetres en qualsevol ordre
  crearTargeta(
    subtitol: "Detalls del producte",
    titol: "Samarreta Base",
  );
}

3.3. Classes, Constructors Nombrats i Mixins

// Mixin per reusar funcionalitat
mixin Loggable {
  void log(String msg) => print("[LOG]: $msg");
}

class Persona {
  String nom;
  int edat;

  // Constructor directament simplificat
  Persona({required this.nom, required this.edat});

  // Constructor Nombrat
  Persona.senseEdat(String nom) : this(nom: nom, edat: 0);
}

// Herència i ús del Mixin
class Estudiant extends Persona with Loggable {
  String cicle;

  Estudiant({
    required String nom,
    required int edat,
    required this.cicle,
  }) : super(nom: nom, edat: edat);

  void mostrarDades() {
    log("Estudiant de $cicle:$nom");
  }
}

3.4. Programació Asíncrona (`Future` i `async/await`)

// Simula una petició a una API externa
Future<String> carregarUsuari() async {
  await Future.delayed(Duration(seconds: 2)); // Espera asíncrona
  return "Joan Garcia";
}

void main() async {
  print("Carregant dades...");
  String nom = await carregarUsuari();
  print("Usuari carregat: $nom");
}
